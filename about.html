Attention Control

Focus Battle: Can You Beat Distraction?

STEM Topic

Attention Control

STEM Branch

Science (Cognitive Science). Explore selective attention and cognitive load. Use mathematics to compare scores across rounds.

Game Description

Find the letter E across three timed rounds: a quiet baseline, a round with simulated notifications, and a retry using a focus strategy. Compare your scores and complete a short learning check.

Learning objectives

  1. Given focused and distracted game results, university student players will explain one observation using selective attention and cognitive load accurately.
  2. During a retry with the same distractions, university student players will apply one focus strategy, justify their choice, and accurately compare their distracted and retry scores.

How learning is checked

Three quiz questions provide immediate explanations. The strategy decision requires a reason. A written reflection connects both concepts to an observation and describes strategy use. Conceptual accuracy and strategy justification need human review. Score improvement is not required.

A fair interpretation

All rounds use the same timing, target count and scoring rule. Rounds two and three use the same message schedule. Practice, fatigue and grid differences can influence results. This activity is a learning demonstration, not a controlled diagnostic test.

Learning design

Inquiry, meaningful strategy choice, immediate quiz feedback and reflection support learning. The game runs locally without collecting personal information or sending results to a server.
